In Lab 4.1, the Pixell River Financial application was extended by separating it into a full-stack monorepo structure containing distinct front-end and back-end applications. The back-end was built using Express and TypeScript, following the Route-Controller-Service-Repository architecture to cleanly separate HTTP handling, business logic validation, and data access responsibilities. Temporary in-memory data that previously lived in the front-end repositories was moved server-side, where it is now managed exclusively by the back-end repositories. CORS middleware was configured to restrict API access to the front-end origin only, with special handling added for GitHub Codespaces environments. The front-end repositories were refactored to use fetch-based API calls, with asynchronous loading and error states added to both the Employees and Organization pages to handle the network-dependent data flow gracefully.
